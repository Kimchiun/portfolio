# Design System

## Overview

**Cinema Frame** — Apple-like scroll film with editorial density. Cool mist grounds, restrained deep teal, brass only on metrics. Project thumbnails lead; UI chrome stays quiet.

## Motion

Sticky scrub on hero and featured project. Mask reveal and light parallax on large media. View Transitions on project thumbnails. `prefers-reduced-motion` and mobile simplify scrub/parallax/cursor.
